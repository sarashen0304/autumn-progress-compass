# 秋招进度指北

成为你秋招的指北针。一个可以直接在浏览器使用的秋招投递管理网页。

## 功能

- 新增、编辑、删除投递记录，并一键推进招聘阶段
- 记录公司、岗位、城市、投递日期、当前阶段、最近安排和下一步行动
- 搜索、阶段筛选、排序、阶段分布和未来安排
- 浏览器本地自动保存与数据导出
- 配合“秋招一键收录”插件识别投递网址

## 数据说明

投递记录保存在每位使用者自己的浏览器中，不会提交到这个 GitHub 仓库，也不会上传到服务器。

从本地文件版切换到其他网址时，浏览器会把它们视为不同网站。切换前请先点击“导出数据”保存 JSON 文件。

## 本地使用

下载后双击 `index.html` 即可使用。
